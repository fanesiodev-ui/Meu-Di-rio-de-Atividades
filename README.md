# Meu-Di-rio-de-Atividades
Diário profissional para Windows, 100% offline: registre atividades em segundos, acompanhe a evolução de demandas e projetos, veja um painel com indicadores e gere relatórios em PDF e Excel. Feito em Python com CustomTkinter e SQLite, com backup automático, executável (.exe) e testes automatizados.
